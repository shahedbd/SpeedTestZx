# Test Net Speed

**Publisher:** Zero Byte Software Solutions · **Category:** Utilities & tools · **Price:** Free
**Store:** https://apps.microsoft.com/detail/9N6FRDSDXM8C

## Description

Test Net Speed is a modern, easy-to-use internet speed testing and network diagnostics app for Windows. It helps you understand exactly how your connection is performing — whether you're streaming video, gaming online, working remotely, attending video calls, or troubleshooting a slow network.

Run a speed test in seconds and get clear, easy-to-read results: download speed, upload speed, ping, and jitter, plus your latest values on a dashboard with connection status. Every completed test is saved automatically to a local history so you can compare performance over time, spot whether slowdowns are temporary or recurring, and see exactly when your connection was last tested.

Beyond speed testing, the app includes practical diagnostic tools — network adapter details, your public IP address, Ping, DNS Lookup, IP Lookup, and Traceroute — wrapped in an approachable interface that serves everyday users while still providing the detail needed for real troubleshooting.

## Features

### Internet speed testing
- **Download speed** — how quickly your connection receives data for browsing, streaming, downloads, and gaming.
- **Upload speed** — how efficiently you can send files, join video calls, back up data, and stream.
- **Ping** — network latency for connection responsiveness.
- **Jitter** — latency consistency, especially useful for gaming, calls, and live streaming.
- **Latest result dashboard** — your most recent download, upload, ping, and jitter values at a glance.
- **Connection status** — instantly see whether your internet connection is currently available.

### Test history & tracking
- **Automatic local history** — every test is saved on your device, no account needed.
- **Browse & compare past results** — spot changes in speed, latency, and stability across tests.
- **Troubleshoot slowdowns** — identify whether poor performance is temporary or a recurring pattern.
- **Last-test info** — quickly see when your connection was last tested.

### Network information & diagnostics
- **Network adapter information** — details about your adapters and active connection.
- **Public IP address** — check the public IP associated with your connection.
- **Ping** — test reachability and response time to any host or website.
- **DNS Lookup** — resolve domain records to diagnose name-resolution issues.
- **IP Lookup** — retrieve useful information for any IP address.
- **Traceroute** — follow the path your data takes and identify routing problems.

### Windows experience & design
- **System tray support** — keep the app accessible from the notification area.
- **Notifications** — helpful updates without keeping the window open.
- **Collapsible sidebar & organized dashboard** — streamlined navigation across speed tests, history, network details, tools, and settings.
- **Modern, accessible design** — dark and light themes, DPI-aware from 100% to 200% scaling, clean navigation, and easy-to-read results.
